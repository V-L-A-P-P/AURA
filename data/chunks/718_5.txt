Возврат по ранее оплаченной кассовой ссылке a) Для возврата по ранее оплаченной кассовой ссылке отличий от ранее реализованных процессов возврата по операциям C2B нет за исключением того, что обязательно требуется передавать значение параметра «payrrn» без «qrcid». Изменение счета ТСП для ранее зарегистрированной кассовой ссылки a) ТСП принимает решение о необходимости смены счета, который был использован в процессе создания (регистрации) кассовой платежной ссылки; b) ТСП обращается с запросом о изменении счета по ранее зарегистрированной кассовой ссылке к Агенту ТСП; c) Агент ТСП передает запрос о смене счета в НСПК; d) НСПК сообщает о результате выполнения запроса Агенту ТСП; e) ТСП уточняет статус операции смены счета у Агента ТСП. Автоматического уведомления ТСП о смене счета по ранее зарегистрированной кассовой ссылки не поддерживается. Регистрация QR-кода для привязки счета ТСП регистрирует QR-код с типом «03» для привязки счета клиента к функциональности оплат по инициативе ТСП; Агент ТСП передает запрос на регистрацию QR-кода для привязки счета в НСПК; Клиент считывает QR-код при помощи своего электронного устройства; Банк Плательщика получает данные QR-кода
