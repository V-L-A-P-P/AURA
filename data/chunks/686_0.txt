Информация на странице может отличаться в зависимости от типа вашей учётной записи. Выберите логин: Каждый раз вы регистрируете заказ в личном кабинете интернет-эквайринга. Ссылку для оплаты вы отправляете покупателю на e-mail, номер телефона, в социальной сети или мессенджере. По ссылке можно указать список товаров. Для чего подойдёт: для компании, у которой нет сайта. Создайте форму оплаты с собственными параметрами — с открытой или заранее заданной суммой. Ссылку можно привязать к кнопке оплаты в социальной сети. Или вы можете использовать личный кабинет для отправки платёжных ссылок. Для чего подойдёт: для сообществ ВКонтакте и в других социальных сетях. Бесплатно создайте свой интернет-магазин и подключите онлайн-оплату через готовый модуль в конструкторе. Для чего подойдёт: для интернет-магазина. Добавьте на сайт небольшой скрипт, который открывает всплывающее окно для ввода данных карты и подтверждения оплаты. Для чего подойдёт: для интернет-магазина, лендинга. Установите на ресурс готовый модуль CMS, настройте его и принимайте оплату на сайте. Для чего подойдёт: для интернет-магазина, который разработан на одной из CMS систем. Установите на ресурс готовый модуль и формируйте ссылки на оплату через CRM-систему. Для чего подойдёт: для интернет-магазина, который использует amoCRM или U-ON.Travel CRM.
