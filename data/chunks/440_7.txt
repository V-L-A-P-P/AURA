В каждой конфигурации предусмотрен набор виджет, наиболее подходящих для выбранного типа торговли: если вы совершаете редкие сделки\управляете портфелем — выбирайте базовую конфигурацию; если вы активно торгуете внутри дня — подойдет конфигурация для дневной или скальперской торговли. Для чего нужны «Табличные виджеты» и их возможности? Табличные виджеты используются для работы с потоками информации по: биржевым котировкам; позициям по счёту; заявкам по счёту; операциям по счёту; совокупному балансу счёта. В каждом табличном виджете есть единая логика работы с колонками: Для виджетов предусмотрены колонки, в каждой из которых отображается свой набор данных. Список колонок, доступный для конкретного виджета можно посмотреть в меню «Колонки» → «Настроить» которое доступно по иконке «шестерёнка». Для экономии места пользователю доступен двустрочный режим. В нём можно расположить 2 ячейки в рамках одного столбца, сгруппировав данные. Трейдер может группировать колонки и сортировать: из меню настройки колонок; в самой таблице, перетаскивая нужные колонки, меняя их местами. В каждом табличном виджете доступна: сортировка А → Я и Я → А по любой колонке; фильтрация по колонке с наименованием\тикером инструмента.
