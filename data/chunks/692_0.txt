Как поменять первичный пароль? В системах интернет-эквайринга есть два логина: -operator и -api. Первый нужен для входа в личный кабинет, а второй — для работы с платёжным шлюзом и не имеет постоянного доступа в личный кабинет. Логины не связаны между собой и менять пароль нужно для каждого отдельно: Зайдите в личный кабинет с логином -api и первичным паролем — они есть в письме с инструкцией для подключения к продуктивной среде. Смените пароль. В нём должно быть не менее 8 символов, латинские символы в нижнем и верхнем регистре, цифры и символы из группы: ! " № ; : ? * ( ) + = / \ < >, . { }. После смены пароля в правом верхнем углу экрана появится виджет «Пароль успешно изменён». Введите логин с окончанием -operator и первичный пароль из письма на почте. Придумайте новый пароль для логина -operator. Он также должен соответствовать требованиям по количеству и типу символов, но при этом не совпадать с паролем для логина -api. Для входа в личный кабинет используйте логин -operator и ваш новый пароль к нему.
